# Каталог DIY

Статический каталог для GitHub Pages. Оформление основано на DNS_koncept_2 и разделе «Ремонт и строительство» DNS: светлая шапка, кнопка «Каталог», мегаменю и плитки с изображениями. Сборка, установка пакетов и серверная база данных не требуются.

## Размещение на GitHub

1. Распакуйте ZIP. Загрузите **содержимое папки**, включая `index.html`, `styles.css`, `app.js`, `data.js`, `data/`, `downloads/` и `.nojekyll`, в корень репозитория.
2. Откройте **Settings → Pages**. Выберите **Deploy from a branch**, ветку с загруженными файлами и папку **/(root)**. Сохраните настройки.
3. Для публикации через Actions вместо предыдущего шага выберите **GitHub Actions**: готовый workflow находится в `.github/workflows/pages.yml` и запускается для ветки `main`.

При ручной загрузке через сайт GitHub убедитесь, что не пропущены скрытые файлы. Оба варианта публикации поддерживают адрес репозитория в подпапке: все ссылки относительные, навигация использует hash-маршруты.

## Локальный просмотр

Откройте `index.html` в браузере. Данные загружаются из `data.js`, поэтому каталог работает и без локального HTTP-сервера. Поиск, переходы, план категорий и карточки не обращаются к внешним сервисам.

## Файлы и обновление

- `data/catalog.json` — единая структура с ID категорий, размещениями, планом и вопросами согласования.
- `data.js` — те же данные для работы напрямую из файла. После правки JSON обновите его командой `python3 scripts/sync_data.py`.
- `downloads/DIY_catalog_updated.xlsx` — Excel с той же редакцией структуры.
- `scripts/validate.py` — проверка ID, ссылок, глубины и правил размещения. Запуск: `python3 scripts/validate.py`.

Новые группировки без указания в исходной структуре или правках не создаются. Категории без основного размещения остаются в заданных подборках либо в плане и реестре.

Одна категория имеет один ID; повторные размещения являются виртуальными ссылками. В `data/navigation-rules.json` перечислены исходные названия и согласованные переименования для проверки группировок. Статус «Закуплено» не означает подтверждённое заведение в учётной системе. Для IV и I кварталов год в исходном плане не указан. Неопределённые решения вынесены в «К согласованию». Изменение JSON не пересобирает Excel автоматически: при выпуске следующей редакции обновите оба представления.

## Источники редакции

- `Вставленный Markdown(20261116-041448).md` — исходная шестиступенчатая структура.
- `коментарии по каталогу DIY.xlsx` — рекомендации, ответы, план категорий и распределение по этапам.

В архиве подготовлена новая статическая версия. Публикация в существующий репозиторий и замена его файлов выполняются отдельно.
